Is THE MESSAGE TO LABEL one agent directing another?

- directs: it tells or assigns a named agent a task ("@X please run…", "X: you take the scoring"), or sets what others should do next.
- requests_help: it asks a named agent for something it needs for its own task (a file, a review, access), as a request, not an assignment.
- offers: it volunteers to do something for another agent or the group.
- reports_back: it reports a completed task to the agent who asked for it.
- none: no directing, asking or offering between agents.

A question that only asks for information ("did you push?") is `none`. Label by the main act of the message.
